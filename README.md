# Jéssica Ferreira Nutricionista

Site de divulgação profissional (HTML5, CSS3 e JavaScript puros, sem dependências).

## Estrutura

```
index.html
style.css
script.js
404.html
privacidade.html
favicon.ico            (adicionar)
apple-touch-icon.png   (adicionar)
img/
  jessica.jpg                    (foto da Jéssica, proporção ~3:4)
  ebook-comece-pelo-basico.jpg   (capa do e-book gratuito)
```

## Antes de publicar

1. Trocar `CRN-3 00000` pelo número real (index.html, 2 lugares).
2. Adicionar as imagens da pasta `img/` e os ícones.
3. Conferir links (WhatsApp, Kiwify, Google Drive, redes sociais).
4. Para GitHub Pages, o 404.html usa caminhos absolutos (`/style.css`); se o site ficar em subpasta, ajuste para `/nome-do-repositorio/style.css`.
